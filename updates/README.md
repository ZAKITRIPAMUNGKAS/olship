# Folder Updates - Tracking & Logs

Folder ini digunakan untuk mencatat dan melacak setiap pembaruan, perbaikan bug, atau fitur baru yang ditambahkan ke dalam aplikasi **Listrindo Jaya Elektrik** (`OLSHOP FIX`).

## Cara Mencatat Log Pembaruan
Setiap kali ada pembaruan besar, perbaikan bug, atau rilis fitur baru, buat dokumen markdown baru di folder ini dengan penamaan format berikut:

```text
YYYY-MM-DD-[nama-pembaruan].md
```

### Struktur Template Log
Setiap file log sebaiknya memiliki struktur berikut:
1. **Ringkasan Pembaruan:** Tabel ringkas berisi tingkat urgensi, komponen yang terpengaruh, deskripsi, dan tindakan perbaikan.
2. **File yang Dimodifikasi:** Daftar file beserta tautannya dan garis besar perubahan kodenya.
3. **Hasil Verifikasi:** Laporan pengujian unit, syntax checking, atau instruksi verifikasi manual.
4. **Tanggal & Pembuat:** Tanggal log ditulis dan nama pengembang/AI pencatat.

---
*Membiasakan pencatatan log pembaruan di folder ini akan mempermudah kolaborasi tim, integrasi CI/CD, dan audit sistem di masa mendatang.*
